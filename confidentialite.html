Règles de confidentialité

Maison Suisse perso est une application privée, utilisée par une seule personne avec son propre compte Google.

  • Données lues (gmail.readonly) : les mails d'alerte immobilière, les confirmations de demande et les dossiers de vente reçus.
  • Envoi (gmail.send) : uniquement un résumé, adressé au propriétaire du compte.
  • Stockage : sur l'ordinateur de l'utilisateur seulement. Rien n'est vendu, partagé ni transmis à des tiers.
  • Révocation : à tout moment, depuis https://myaccount.google.com/permissions.

L'usage des données reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'usage limité (Limited Use).
